    Inside the project

    Four pieces working together

    The full application combines complementary retrieval stores with an agent and safety checks. Evidence, not generated prose, is used to assemble citations.

    01 · RETRIEVE

    Documents + graph

    Qdrant finds relevant text; Neo4j follows explicit relationships.

    02 · FUSE

    Rank the evidence

    Reciprocal Rank Fusion and a cross-encoder combine and rerank results.

    03 · ANSWER

    Bounded agent

    A LangGraph agent uses tools within a fixed iteration limit.

    04 · VERIFY

    Guardrails + citations

    NeMo rails check input and output; citations come from retrieved records.

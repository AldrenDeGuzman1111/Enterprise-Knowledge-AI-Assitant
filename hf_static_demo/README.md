# Aldren's Enterprise Knowledge Assistant

An interactive, static walkthrough of the Enterprise Knowledge Assistant project. Explore
an example multi-hop answer and how vector retrieval, a knowledge graph, guardrails, and
citations fit together.

> **Demo limitation:** This Space is a static showcase. Its sample answer is illustrative;
> it does not call the live model, FastAPI service, Qdrant, or Neo4j.

The full Docker app described in [`README_HF.md`](https://github.com/AldrenDeGuzman1111/Enterprise-Knowledge-AI-Assitant/blob/master/README_HF.md)
requires Hugging Face PRO for Docker Space hosting. The repository includes the Docker
deployment files and instructions for running the complete application elsewhere.
